About the Game

Dorothy's Job is a fast-paced isometric twin-stick shooter starring Dorothy, a buff maid tasked with maintaining a Dark Lord's mansion.

Master a high-stakes gameplay loop that forces you to balance heavy-duty cleaning with intense combat, all while racing against time.

Mechanics Designer
  • Designed and iterated the core gameplay loop combining active combat with cleaning mechanics.
  • Collaborated with art and programming teams to implement systems aligned with design intent.
  • Maintained clear design documentation (GDD) to ensure cross-departmental alignment.

As part of a 6-person design core, my primary focus was creating mechanics wich blended cleaning and combat.

Key Constraint: Standard twin-stick tropes (like breaking props into debris) were discarded—Dorothy is meant to clean the mansion, not destroy it.

Key Challenges Addressed

Procedural Generation Since the programming key feature was the procedural generated levels, we worked closely to keep them balacnced and have backup plans in case so mething failed.
Visual Clarity Adjusted the two floor dirt types, bullets, status effects and UI to remain visible throughout gameplay..
Game built around a character Created the mechanics, game and visuals around the character Dorothy, which affected gameplay decisions.
